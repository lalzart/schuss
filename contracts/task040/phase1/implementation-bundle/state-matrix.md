> Status: ready

|---|---|---|---|---|---|---|---|---|
| Initialization | Load schema-valid saved values or the frozen defaults; accepted values are authoritative. | Clear all pending transition changes, Bloom token, gesture timers, and soft-takeover arms except FX-A/B arms required by recalled mode values. | Zero phases, resonators, filters, envelopes, diffusion, gates, and diagnostics, then initialize the four-stage cycle without emitting a transition. | Zero grain and diffusion storage; write heads become zero; Freeze is false unless a valid recalled snapshot says true. | Seed xorshift32 with 0x43494e44; zero mutation offsets, ledger energies, refractory flags, rotor indices, transition count, and event counters. | Start ingress sequence at one; no receipt or accepted event is synthesized. | Return one accepted-state snapshot and zeroed diagnostics; no MIDI or device feedback. | Prepare accepts exactly 48 kHz and maximum block frames 1 through 512; invalid configuration fails before processing and yields no partial state. |
| Reset | Preserve current public parameter values, source/scale/mode/target, Lock, Freeze, and captured grain data. | Clear pending transition values, Bloom, button timers, takeover arms, and pending Wake energy; commit current controls as new ramp origins. | Restore stage phase, mutation offsets, Wake voices, effects crossfade, output gate, and musical cycle to the reference state; do not erase the captured buffer. | Preserve grain samples and the current frozen write head; clear transient diffusion and active grain voices. | Restore seed 0x43494e44, zero ledger/rotors/refractory state, transition count, and scheduled afterstrikes. | Increment reset-count and record the accepted Reset event; later ingress sequence remains monotonic. | Snapshot shows preserved controls plus reset musical state; raw Reset selector remains a separate receipt diagnostic. | Tap release before 57600 held samples applies at that sample. Duplicate press and orphan release are ignored and counted; block partition cannot change the result. |
| Mode change | Cycle CLEAN, FILT, DRIVE or Source/Scale/Target only through their public facets; retain per-mode FX-A/B values. | Latch categorical change for the next stage transition; arm FX-A/B soft takeover with a two-MIDI-step crossing window. | Crossfade the old and new effect state without changing graph topology; source/scale/target changes use the declared transition latch. | Grain capture and write head are unchanged. | Scheduler/ledger is unchanged; audio dirt never feeds it. | Record receipt, pending latch, accepted transition, and takeover accept/reject as distinct ordered events. | Accepted-state feedback changes only when the latch commits; raw CC preview may lead it. | Same-sample events use ingress sequence. A hold at sample 28800 cycles Scale once; release after hold does nothing; shorter release cycles Source. |
| State recall | Atomically validate and load the exact project/instrument revision; invalid or stale hashes fail closed. | Restore declared transition-pending values and Bloom only if present in the schema; arm FX-A/B takeover. | Restore all declared musical state required by the saved snapshot; process handles, target/backend/provider IDs, and runtime factory IDs are never saved as graph identity. | Restore captured buffer and write heads only when exact schema, length, and hash match; otherwise reject the whole recall. | Restore seed, mutation, ledger, rotor, refractory, and counters named by the state schema; exclude process-local ingress count. | Start a new process-local receipt epoch while preserving canonical saved event provenance. | Return the accepted restored snapshot and a recall diagnostic; physical encoder synchronization remains deferred. | Recall occurs between process calls, never mid-block. No partial state survives a validation failure. |
| Disconnect/reconnect | Keep the last accepted instrument controls; no synthetic controller state change occurs. | Keep bounded transition changes already accepted; clear incomplete button presses on explicit endpoint-loss input in a future device adapter. | Audio and scheduler continue at the last safe state; host Reset/Panic remain available. | No buffer or head change. | No random, ledger, or rotor change. | Synthetic Phase 2 has no endpoint events; future endpoint loss must be separately typed and counted. | Accepted state remains distinct from endpoint state; Phase 1 makes no connected-device claim and sends no feedback. | N/A — endpoint discovery, open, loss, automatic reconnect, and resynchronization are outside this vertical slice and cannot be inferred from synthetic events. |
| Non-finite recovery | Preserve finite public control targets; reject non-finite input values before acceptance. | Clear a pending value only if it is the source of the invalid state; otherwise retain pending controls. | Clear the affected voice/state owner, increment non-finite-clears, gate the affected contribution, and prevent NaN/Inf from reaching stereo output. | Zero only the contaminated fixed-capacity state region and its head; do not scan or allocate dynamically. | Clear contaminated ledger energy and refractory state; no deferred burst is emitted. | Record one stable containment diagnostic with node key and sample index; do not log from the processing path. | Snapshot reports finite accepted state plus the diagnostic; raw invalid input is never displayed as accepted. | Containment occurs before the sample is mixed. Output remains within 0.891250938 and the reference render requires zero containment events. |

## State equivalence

For the same exact project snapshot and sorted event stream, semantic equivalence
means byte-equal accepted-state snapshots and event ledgers after excluding the
process-local receipt epoch, ingress counters, wall-clock duration, host handles,
and device identity. Host-signal repeatability is byte equality for repeated
runs and retained artifacts; cross-block audio permits at most `1e-6` absolute
sample delta while ledgers remain byte-exact. Reset equivalence additionally
requires the next 16-cycle ledger to equal the reference. No physical endpoint,
callback deadline, or listening equivalence is part of Phase 1.
