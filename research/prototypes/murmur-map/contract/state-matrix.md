## State equivalence

For the authenticated macOS arm64 environment, identical default/reset state,
seed, accepted semantic timeline, and supported block partitions must produce
byte-identical canonical route/event traces and stereo PCM. A captured
`CoreState` is **reset-boundary equivalent**: after transactional recall, fresh
voice construction, and the same future semantic events, future musical traces
and PCM are byte-identical. Arbitrary mid-tail sample-continuous equivalence is
excluded because active oscillator, envelope, bridge, decimator, and DC states
are deliberately reconstructed. UI repaint timing, host callback timestamps,
MIDI endpoint handles/names, ingress counters, and raw controller messages are
also excluded from musical state equivalence.
