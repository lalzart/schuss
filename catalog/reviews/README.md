# Catalog review packets

Review packets are deterministic derivatives of retained snapshots. They may
group, sample, and assess evidence, but they do not revise the source snapshot
or establish final Schuss taxonomy.

`phase-3-inventory-review-v0/` binds every input and output file by SHA-256. It
contains issue-impact groups, object-count reconciliation, all legacy name
overloads, zombie groups, partial-graph reasons, graph status matrices, facet
coverage, and four deterministic 25-record review samples.

The review summary's taxonomy, migration, and compilation-readiness levels are
explicit engineering judgment. The underlying counts and references remain
separate factual evidence.
