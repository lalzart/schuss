# Mutable Eurorack Braids physical source closure v1

This package contains exactly the twelve Braids files required by the reusable
Task 038 adapter. `SOURCE_PACKAGE.json` is generated from physical bytes and
references `schuss-source-release-000008@1`; it owns no upstream identity,
licensing, catalog, graph, provider, or runtime semantics.

The package is intentionally separate from Task 036's Ksoloti Mutable closure.
Matching individual file hashes do not make distinct source releases or
path-sensitive closures interchangeable.
