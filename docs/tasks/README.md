# Task contracts

This directory contains only live routing guards and the current product-task
contract:

- `012b-object-drawer-and-transparent-graph-canvas.md` is a retirement notice;
  it is not runnable work.
- `018-full-gills-implementation-and-parameter-control-mapping.md` is the only
  ready product-task contract. Its implementation has not started.

Completed task detail is indexed in `../HISTORY.md` and recoverable byte for
byte from Git. Accepted architectural choices must move into ADRs, while exact
outputs and proof remain in schemas, records, record sets, and `evidence/`.

Every new implementation task must state its goal and reason, in-scope and
out-of-scope work, inputs and deliverables, acceptance tests, decisions it may
make, and decisions it must not make. Completing a task does not authorize the
next task, Git publication, or hardware action.
