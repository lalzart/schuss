# Mutable Braids v1 adapter

This repository-internal C++17 adapter owns the reusable source mechanics for
constructing and rendering the selected Braids `MacroOscillator` models and
for seeding the selected stmlib random implementation. Its two physical source
packages resolve and validate the exact upstream bytes at CMake configuration.

It is not a Schuss catalog implementation, graph, provider, runtime factory,
public SDK, or claim of target, real-time, audible, or production readiness.
Musical recipes, allocation, envelopes, decimation, mixing, and controls remain
owned by each instrument consumer.
