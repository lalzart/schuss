## State equivalence

Repeatability means byte equality for canonical event traces, allocation traces,
metrics JSON, manifests, and signed 32-bit PCM WAV files for the same seed and
accepted control timeline on the declared host toolchain, including supported
outer block partitions. Musical timing fixtures additionally compare exact
integer absolute frames and normalized rational positions. Absolute paths,
process IDs, wall-clock timestamps, host handles, MIDI endpoint identities, and
device identities are deliberately absent from evidence artifacts.
