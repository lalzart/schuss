# Wirefall state-by-operation matrix

> Status: ready

All frame counts below are at the fixed 48 kHz base rate. An operation event at
absolute frame `n` is applied before audio frame `n`. No row authorizes a host,
controller, device, preset, or external-clock implementation.

## State equivalence

Reset equivalence is normalized byte equality. Compare two canonical Core state
snapshots taken immediately before frame `n+480` becomes normal output after
the same Reset event. Exclude only absolute event `sample_index` values and
monotonic diagnostic counters; do not exclude oscillator phases, smoothing
state, FIR/delay contents and heads, SVF/DC state, envelope coordinates,
scheduler phase/err/rate, pending state, accepted/drop counts within the replay,
or mode/ratio state. After the same accepted event suffix, the complete event
ledger and rendered PCM bytes must also be byte-identical.

Block equivalence uses the same relation without exclusions: one accepted
absolute event stream rendered in partitions `1,16,64,257,512` must produce
byte-identical ledgers, PCM, and canonical final snapshots. Host block sizes,
host handles, physical endpoint identities, UI refresh times, and wall-clock
timestamps are not Core state and cannot appear in these artifacts.
