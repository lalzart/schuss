## State equivalence

Program-state equivalence means exact equality of the sixteen quantized adapter
parameter values and the state-schema/parameter-contract fingerprint. After
recall, DSP equivalence means exact float PCM and normalized accepted
Source/Lock/FX/Target/Scale equality against a separately fresh Core given the
same desired program, event order, block partition, and enough frames for the
declared source gesture queue to settle. Captured audio, mutation values,
reverb/modal/grain history, absolute sample, RNG progress after initialization,
gesture queues, ingress counters, diagnostics, MIDI receipts, scope history,
host handles, endpoint identities, editor geometry, and wrapper service
parameters are deliberately excluded and reset rather than compared.
