## State equivalence

For one declared sample rate, seed, initial/reset state, source samples, semantic
control/action timeline, and generation mode, decision traces must be byte
identical across the supported callback partitions. Stereo PCM must be byte
identical on the authenticated macOS arm64 Release environment and
signal-equivalent within `1e-7` elsewhere using the same compiler floating-point
mode. Version-1 recall is **reset-boundary musical-state equivalent**: after the
explicit empty-capture result and identical future source input, future
decisions and PCM match the captured continuation once the same valid capture
span is rebuilt. Active voice/body tails, retained capture PCM, absolute
wall-clock timestamps, UI repaint timing, callback timestamps, endpoint
handles/names, xrun estimates, and host ingress counters are deliberately
excluded.
