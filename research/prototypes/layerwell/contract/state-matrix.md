# Layerwell Desktop Meta-Instrument state-by-operation matrix

> Status: ready

The callback owner is the sole writer of Core state. Host/UI/controller state is
a projection of accepted snapshots, never a raw-input mirror.

## State equivalence

For one build and the frozen experiment, repeatability means byte equality of
canonical event/state/controller JSON and generated PCM bytes across supported
block partitions; exact integer equality of capture boundaries, layer-owner
indices, session length/phase, source advance counts, event counts, and limiter
counts; and SHA-256 equality of every committed layer in preservation cases.

Freshly reset instances are musically equivalent when their public source
snapshots, Layerwell accepted controls, session state, buffer ownership and
occupied flags, zeroed committed sample ranges, and deterministic source seed
state agree. C++ object padding, allocator addresses, host handles, absolute
filesystem paths, endpoint identifiers, wall-clock time, GUI component state,
unsent feedback queue positions, and generated build paths are deliberately
excluded. Floating output is compared as the exact generated PCM representation
within the same compiler build; cross-toolchain bit identity is not claimed.
